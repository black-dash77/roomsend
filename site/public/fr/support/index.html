Aide

Les questions que RoomSend pose le plus souvent. Pour le reste, écris-nous.

Personne dans la pièce ?

  1. Les deux appareils sont-ils sur le même Wi-Fi ?

    Connecte-les au même réseau. Un réseau invité compte comme un autre réseau.

  2. RoomSend ou LocalSend est-il ouvert à l'écran sur l'autre appareil ?

    Ouvre-le. Les appareils ne répondent que quand l'app est au premier plan.

  3. RoomSend a-t-il accès au réseau local ?

    Sur l'iPhone, ouvre Réglages, Confidentialité et sécurité, Réseau local, et active RoomSend.

  4. Certains réseaux séparent les appareils, dans les hôtels, les bureaux ou les écoles. Garde Balayer le réseau activé dans les Réglages de RoomSend, ou ajoute l'appareil par son adresse avec le bouton + de l'écran Pièce.

Questions

Où vont les fichiers reçus ?

Dans l'app Fichiers, sous Sur mon iPhone, RoomSend. Les photos et vidéos vont aussi dans Photos quand Photos dans Photos est activé.

À quelles apps puis-je envoyer ?

LocalSend sur Android, Windows, macOS, Linux et iOS, et RoomSend sur les autres iPhone, tant qu'ils sont sur le même Wi-Fi.

L'autre appareil demande un code PIN.

Tape le code affiché sur cet appareil. Pour en demander un toi-même : Réglages, Demander un code PIN.

Les transferts sont-ils chiffrés ?

Oui, par défaut : HTTPS, et RoomSend vérifie le certificat de l'autre appareil avec l'empreinte qu'il a annoncée. Un cadenas ouvert signale un appareil qui ne chiffre pas. Le partage par lien passe en HTTP simple.

Comment marche le partage par lien ?

Dans la feuille d'envoi, Partager par lien affiche une adresse et un QR code. Tout navigateur du même Wi-Fi l'ouvre et télécharge les fichiers, tant que RoomSend reste ouvert.

Puis-je envoyer à plusieurs appareils d'un coup ?

Oui. Dans le carrousel de la feuille d'envoi, choisis Toute la pièce.

Comment changer le nom de mon appareil ?

Dans Réglages, touche le nom pour en taper un autre, ou touche le bouton de mélange pour en tirer un.
